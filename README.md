## What it does

`main.py` writes one line — the single line this older self would send back
to the younger one — to `/output/entry.txt`. The line is 126 characters,
one breath, no explanation, no second sentence.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic: no clock, no network, no input. Running it twice produces
byte-identical output.
